# Data directory

This directory contains the authoritative dataset file:

```text
multisine_signals_v1.0.0.csv
```

The file contains:
- 750 records;
- one sample identifier column: `ID`;
- 12 receiver-side RSSI/power measurement columns in mW;
- one class-label column: `Indicator`.

The measurement columns and class-label mapping are defined in:

```text
../docs/DATA_DICTIONARY_v1.2.1.md
../metadata/DATA_DICTIONARY_v1.2.1.csv
```
